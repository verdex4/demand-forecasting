# Прогноз востребованности специальностей в вузе

Веб-приложение для анализа и прогнозирования востребованности направлений подготовки (специальностей) в высших учебных заведениях.

Система помогает вузам оптимизировать приёмные кампании, корректировать учебные планы и эффективнее распределять ресурсы на основе данных.

## 🛠️ Технологический стек

- **Backend:** Python, FastAPI, PostgreSQL, SQLAlchemy, Pydantic
- **Frontend:** HTML, CSS, JavaScript

## 📋 Требования

- **Python 3.10+** ([скачать](https://www.python.org/downloads/))
- **PostgreSQL 14+** ([скачать](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads/))
- **pip** (устанавливается вместе с Python)

## 🐘 Установка PostgreSQL

**Windows:**

Установка базы данных:
1. Скачайте установщик с [официального сайта](https://www.enterprisedb.com/downloads/postgres-postgresql-downloads/)
2. Запустите .exe-файл и следуйте мастеру установки
3. На шаге Password задайте пароль для пользователя postgres — запомните его!
4. Оставьте порт по умолчанию: 5432

Создание базы данных:
1. Откройте SQL Shell (psql). Он устанавливается вместе с базой данных.
2. Нажимайте Enter до поля `Пароль пользователя postgres:`
3. Введите пароль, заданный ранее.
4. После входа введите команду ```CREATE DATABASE demand_forecasting;```

## 🚀 Установка проекта

### 1. Клонируйте репозиторий

```bash
git clone <ссылка-на-репозиторий>
cd <имя-папки-проекта>
```

### 2. Создайте виртуальное окружение (рекомендуется)

**Linux / macOS:**

```bash
python3 -m venv venv
source venv/bin/activate
```

**Windows:**

```bash
python -m venv venv
venv\Scripts\activate
```

### 3. Установите зависимости

```bash
pip install -r backend/requirements.txt
```

### 4. Создайте файл конфигурации .env

В главной папке проекта создайте рабочий файл. Для этого скопируйте шаблон командой:
```bash
copy .env.example .env
```

Откройте созданный файл .env текстовым редактором и укажите настройки для подключения к базе данных:
- В строку `user` впишите postgres (это стандартное имя пользователя)
- В строку `password` впишите ваш личный пароль, который вы придумали раньше
- В строку `host` впишите localhost:5432 (это адрес для запуска программы на вашем компьютере)
- В строку `database_name` впишите имя созданной базы данных (в этой инструкции мы используем `demand_forecasting`)

## ▶️ Запуск проекта

Перейдите в папку `backend` и запустите сервер через `uvicorn`:

```bash
cd backend
uvicorn app.main:app --reload
```

> **Примечание:** Флаг `--reload` включает автоматическую перезагрузку сервера при изменении кода (удобно для разработки).
